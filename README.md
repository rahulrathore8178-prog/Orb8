# Gamified LMS Platform for Coders

A scalable, gamified Learning Management System (LMS) for coders, inspired by Duolingo.  
Built with the MERN stack and Next.js for high-performance, interactive learning.

---

## Features

- 🎮 **Gamified Learning:** Interactive coding challenges and real-time ranking system to boost engagement.
- 🏆 **Real-Time Leaderboards:** Compete with other users and track your progress instantly.
- 👥 **User Connectivity:** Social features to connect, collaborate, and learn together.
- 🔒 **Secure Payments:** Integrated Stripe for seamless and secure transactions.
- 🤖 **AI/ML Personalization:** Adaptive learning paths, challenge difficulty, and progress analytics powered by Python, TensorFlow, and scikit-learn.
- 🚀 **Scalable & Reliable:** Dockerized deployments, CI/CD pipelines, and AWS hosting for 10,000+ concurrent users (scalable to 100k+).
- ⚡ **Modern Tech Stack:** MERN (MongoDB, Express.js, React.js, Node.js), Next.js, Python, TensorFlow, scikit-learn, Stripe, Docker, AWS.

---

## Tech Stack

- **Frontend:** React.js, Next.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI/ML:** Python, TensorFlow, scikit-learn
- **Payments:** Stripe
- **DevOps:** Docker, AWS, CI/CD
